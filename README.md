**Mavzu:** Intellektual mulk huquqida Individuallashtirish vositalari va oshkor etilmagan axborotga bo'lgan huquqlar

**Talaba:** ABDUVOXIDOV SHOHBOZBEK SHERZODBEK O'G'LI
**Ilmiy rahbar:** ABROROV SHOXRUX ABROR O'G'LI

## Qanday ochish

1. `index.html` faylini ikki marta bosing — brauzer (Chrome, Edge, Firefox) ochiladi.
2. Internet ulanishi kerak (reveal.js CDN'dan yuklanadi). Birinchi ochilishdan keyin brauzer kesh saqlaydi.

## Navigatsiya

| Tugma | Vazifa |
|-------|--------|
| `→` / `Space` | Keyingi slayd |
| `←` | Oldingi slayd |
| `Esc` yoki `O` | Hamma slaydlarni umumiy ko'rinishda ko'rish |
| `F` | To'liq ekran rejimi |
| `S` | Speaker notes (lektorga eslatma) ochiladi |
| `B` | Ekranni qoraytirish (tanaffus uchun) |

## PDF ga eksport qilish

1. Brauzerda manzil satriga `?print-pdf` qo'shing:
   `file:///.../presentation/index.html?print-pdf`
2. `Ctrl+P` (Print)
3. Destination: **Save as PDF**
4. Margins: **None**, Layout: **Landscape**
5. Background graphics: **yoqilgan** (✓)
6. Save bosing — har bir slayd alohida sahifa bo'ladi.
